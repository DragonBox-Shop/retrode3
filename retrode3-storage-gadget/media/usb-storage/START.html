RETRODE 3
Quick start & troubleshooting

Welcome to Retrode 3

This page is stored on the Retrode 3 USB drive and works offline. Your Retrode provides a local web interface over its USB network connection. Internet access is not required to use it.

Get started

  1. Connect Retrode 3 to your computer with a data-capable USB cable and let it finish booting.
  2. Wait for your computer to set up the USB network interface automatically. The USB drive and USB network are separate functions of the same device.
  3. Open the built-in web interface using either address:
Recommended: http://retrode.local/
Alternative: http://172.31.255.1/

The .local name uses mDNS/Bonjour and might not work on every computer. The numeric address does not depend on name discovery.

What should happen automatically?

Retrode 3 uses USB CDC-NCM (USB Ethernet). It has address 172.31.255.1; the connected computer should receive 172.31.255.2 with subnet mask 255.255.255.252 via DHCP.

No gateway and no DNS server are supplied over USB. This is intentional: your normal Wi-Fi/Ethernet internet connection should remain unchanged. A message such as "Unidentified network" or "No internet" for the Retrode USB adapter does not by itself indicate a problem.

If the web interface does not open

  1. Try http://172.31.255.1/ first. Enter the address in the browser's address bar, not in a search box. Use http://, not https://.
  2. Wait for the Retrode to boot and reconnect the USB cable if necessary. Check that it is a data cable rather than a charge-only cable.
  3. Check whether a USB NCM/Ethernet network adapter appeared on your computer and is configured for automatic IPv4 (DHCP).
  4. If the adapter has no IPv4 address, renew its DHCP lease or disconnect/reconnect the adapter.
  5. If DHCP still fails, manually assign the computer's USB adapter IPv4 address 172.31.255.2, subnet mask 255.255.255.252 (prefix /30). Leave gateway and DNS empty. Do not change your normal internet adapter.
  6. VPNs, firewalls or an overlapping local subnet may interfere. If retrode.local alone fails, use the numeric address.

Windows 11

Windows 11 includes a USB-NCM class driver (UsbNcm.sys). Normally no driver download is required.

  1. Open Settings > Network & internet > Advanced network settings and identify the newly connected Ethernet/USB adapter.
  2. Open its properties and ensure IPv4 is set to Obtain an IP address automatically.
  3. For a manual fallback, press Win+R, enter ncpa.cpl, open the new adapter's Properties > Internet Protocol Version 4 (TCP/IPv4) > Properties and enter the values above. Leave default gateway and DNS empty.
  4. If no USB network adapter appears, inspect Device Manager for an NCM or unrecognized device. Reconnect the device and check Windows Update.

Windows 10 and earlier: Microsoft's standard USB-NCM class driver is listed for Windows 11, not Windows 10. Automatic networking is therefore not guaranteed on older Windows versions. Do not install random third-party drivers to force it.

Linux

Most current distributions automatically load the cdc_ncm driver. NetworkManager normally acquires the address by DHCP.

ip link
ip -4 addr show
ping -c 3 172.31.255.1

If you can identify the new USB adapter but it does not connect, enable DHCP for that adapter in your network settings. Advanced manual fallback (replace USB_IFACE with its real interface name):

sudo ip link set USB_IFACE up
sudo ip addr replace 172.31.255.2/30 dev USB_IFACE
ping -c 3 172.31.255.1

These ip commands are temporary and do not change persistent network settings. Do not add a default route via Retrode 3.

macOS

  1. Open System Settings > Network and select the USB/Ethernet service corresponding to Retrode 3.
  2. Under Details > TCP/IP, set Configure IPv4 to Using DHCP. Renew the DHCP lease if necessary.
  3. If automatic configuration fails, select Manually and enter IP address 172.31.255.2 and subnet mask 255.255.255.252. Leave the router field empty.
  4. Use the numeric web address if retrode.local does not resolve.

Internet access and Wi-Fi

The Retrode web interface, USB network and local file transfer do not require internet access. Providing the Retrode with internet through your computer for updates, time synchronization or online images is an optional, separate configuration, requiring host routing/NAT and DNS. The USB DHCP connection alone does not enable that.

Internet Connection Sharing on Windows or macOS may change the USB adapter's addresses and conflict with the fixed 172.31.255.0/30 network. Do not enable it blindly. Wi-Fi configuration is independent of the USB connection; this quick-start guide does not assume a Wi-Fi access point is active.
