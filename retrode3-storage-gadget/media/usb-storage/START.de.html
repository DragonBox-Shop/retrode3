RETRODE 3
Schnellstart & Fehlerbehebung

Willkommen bei der Retrode 3

Diese Seite liegt auf dem USB-Laufwerk der Retrode 3 und funktioniert auch offline. Die Retrode stellt ihre Weboberfläche über eine eigene USB-Netzwerkverbindung bereit. Dafür wird kein Internetzugang benötigt.

Erste Schritte

  1. Verbinde die Retrode 3 mit einem USB-Datenkabel mit Deinem Computer und warte, bis sie vollständig gestartet ist.
  2. Warte, bis Dein Computer die USB-Netzwerkverbindung automatisch eingerichtet hat. USB-Laufwerk und Netzwerk sind zwei Funktionen desselben Geräts.
  3. Öffne die integrierte Weboberfläche über eine dieser Adressen:
Empfohlen: http://retrode.local/
Alternative: http://172.31.255.1/

Der Name retrode.local verwendet mDNS/Bonjour und funktioniert nicht auf jedem Computer. Die numerische Adresse funktioniert ohne Namensauflösung.

Was sollte automatisch passieren?

Die Retrode 3 verwendet USB CDC-NCM (Netzwerk über USB). Sie besitzt die Adresse 172.31.255.1. Dein Computer sollte per DHCP 172.31.255.2 mit der Subnetzmaske 255.255.255.252 erhalten.

Über USB werden absichtlich weder Standard-Gateway noch DNS-Server verteilt. Deine normale Internetverbindung über WLAN oder Ethernet bleibt dadurch erhalten. Meldungen wie „Nicht identifiziertes Netzwerk“ oder „Kein Internet“ beim Retrode-USB-Adapter bedeuten nicht automatisch einen Fehler.

Wenn die Weboberfläche nicht erreichbar ist

  1. Versuche zuerst http://172.31.255.1/. Gib die Adresse in die Adresszeile des Browsers ein, nicht in die Suche. Verwende http://, nicht https://.
  2. Warte, bis die Retrode gestartet ist, und stecke das USB-Kabel bei Bedarf neu an. Es muss Daten übertragen können; ein reines Ladekabel reicht nicht.
  3. Prüfe, ob ein neuer USB-NCM-/Ethernet-Netzwerkadapter erscheint und IPv4 auf „Automatisch (DHCP)“ eingestellt ist.
  4. Wenn der Adapter keine IPv4-Adresse bekommt, erneuere die DHCP-Lease oder trenne und verbinde den Adapter neu.
  5. Falls DHCP weiterhin nicht funktioniert, trage nur beim Retrode-USB-Adapter die IPv4-Adresse 172.31.255.2 und die Subnetzmaske 255.255.255.252 (Präfix /30) manuell ein. Gateway und DNS bleiben leer. Verändere nicht Deinen normalen Internetadapter.
  6. VPNs, Firewalls oder überlappende lokale Netzbereiche können Probleme verursachen. Falls nur retrode.local nicht funktioniert, nutze die numerische Adresse.

Windows 11

Windows 11 bringt den USB-NCM-Treiber (UsbNcm.sys) mit. Normalerweise muss kein Treiber heruntergeladen werden.

  1. Öffne Einstellungen > Netzwerk und Internet > Erweiterte Netzwerkeinstellungen und suche den neu hinzugekommenen Ethernet-/USB-Adapter.
  2. Prüfe in dessen Eigenschaften, ob IPv4 auf IP-Adresse automatisch beziehen steht.
  3. Für eine manuelle Einrichtung: Drücke Win+R, gib ncpa.cpl ein und öffne beim neuen Adapter Eigenschaften > Internetprotokoll Version 4 (TCP/IPv4) > Eigenschaften. Trage die oben genannten Werte ein. Gateway und DNS bleiben leer.
  4. Erscheint kein USB-Netzwerkadapter, prüfe im Geräte-Manager, ob ein NCM- oder unbekanntes Gerät auftaucht. Verbinde die Retrode erneut und prüfe Windows Update.

Windows 10 und älter: Microsoft führt seinen standardmäßigen USB-NCM-Klassentreiber für Windows 11 auf, nicht für Windows 10. Auf älteren Versionen funktioniert die automatische Netzwerkeinrichtung deshalb nicht garantiert. Installiere dafür keine beliebigen Treiber aus unbekannten Quellen.

Linux

Die meisten aktuellen Distributionen laden den Treiber cdc_ncm automatisch. NetworkManager richtet die Adresse normalerweise per DHCP ein.

ip link
ip -4 addr show
ping -c 3 172.31.255.1

Falls der neue USB-Adapter erkannt wird, aber keine Verbindung bekommt, aktiviere DHCP für diesen Adapter in Deiner Netzwerkverwaltung. Manuelle Testkonfiguration (ersetze USB_IFACE durch den tatsächlichen Namen des Adapters):

sudo ip link set USB_IFACE up
sudo ip addr replace 172.31.255.2/30 dev USB_IFACE
ping -c 3 172.31.255.1

Diese ip-Befehle gelten nur vorübergehend. Richte keine Standardroute über die Retrode 3 ein.

macOS

  1. Öffne Systemeinstellungen > Netzwerk und wähle den USB-/Ethernet-Dienst der Retrode 3.
  2. Stelle unter Details > TCP/IP die IPv4-Konfiguration auf DHCP. Erneuere bei Bedarf die DHCP-Lease.
  3. Falls DHCP nicht funktioniert, wähle Manuell und trage 172.31.255.2 als IP-Adresse sowie 255.255.255.252 als Teilnetzmaske ein. Das Router-Feld bleibt leer.
  4. Verwende die numerische Webadresse, wenn retrode.local nicht aufgelöst wird.

Internetzugang und WLAN

Die Weboberfläche, die USB-Verbindung und lokale Dateiübertragungen funktionieren ohne Internetzugang. Soll die Retrode über den Computer ins Internet gelangen, etwa für Updates, Zeitsynchronisation oder Online-Bilder, ist das eine zusätzliche, optionale Konfiguration. Dafür benötigt der Computer Routing/NAT und die Retrode eine passende DNS-Konfiguration. DHCP allein reicht dafür nicht.

Die Internetfreigabe von Windows und macOS kann die USB-Netzwerkadressen ändern und so mit unserem festen Netz 172.31.255.0/30 kollidieren. Schalte sie daher nicht unüberlegt ein. Die WLAN-Konfiguration ist unabhängig von USB; diese Anleitung setzt keinen aktiven WLAN-Access-Point voraus.
