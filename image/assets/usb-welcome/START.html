Welcome to Retrode3

Open http://172.31.255.1/ over USB (or retrode3.local if supported by your computer).

The USB address is fixed. Retrode3 supplies an address to your computer without changing its Internet gateway or DNS settings. Configure Wi-Fi in the web interface for Internet access on Retrode3.

If your browser warns about HTTP, continue only when you are connected to your own Retrode3. Use the explicit http:// address above.

The Retrode3 exposes a USB NCM network connection. Your computer can obtain an address automatically via DHCP. If necessary, activate the separate USB network connection in your network settings. If DHCP still fails, configure 172.31.255.2 with netmask 255.255.255.248 on the USB network adapter.

This welcome disk is read-only and does not contain your ROMs. Cartridge dumps are accessed through the web interface and, once configured, through Samba over the USB network.

USB serial is available as a separate CDC ACM interface. SSH is optional and is not needed for normal Retrode3 operation.
