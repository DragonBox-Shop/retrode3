Help & documentation

Quick start guide for reading cartridges and managing ROMs. The full instructions are available online.

Quick start

  1. Connect Retrode3 to your computer and open its web page.
  2. Insert a cartridge. The slot indicator shows whether a cartridge is physically present.
  3. Select a supported reader and use Detect Cartridge, then Read ROM.
  4. Access completed dumps in the File Manager or via Samba.
